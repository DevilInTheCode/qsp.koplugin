# Devilsoft Casino — QSP-плеер для KOReader

Плагин для [KOReader](https://koreader.rocks/), добавляющий полноценный
плеер QSP-квестов (текстовых игр формата `.qsp`).

## Возможности

- **Запуск QSP-игр прямо в KOReader** — без ПК и сторонних приложений.
- **Формат `.qsp`** — Instant Millionaire, Asatama, Zero Kill Beta и другие.
- **Полноценный HTML-рендер** — текст, картинки, `<b>`, `<i>`, `<center>`,
  кликабельные ссылки `<a href="EXEC:...">`.
- **Кнопки действий** — только активные (неактивные скрываются автоматически).
- **Панель объектов** — МЕНЮ, ДНЕВНИК, КНИГИ и т.д.
- **Регулировка размера шрифта** — кнопки `A-` / `A+` в заголовке.
- **Прокрутка длинного текста** — свайпами вверх/вниз.
- **Сохранение/загрузка** — через `QSPSaveGameAsData` / `QSPOpenSavedGameFromData`.
- **Работает на Kindle Paperwhite 4 (10-е поколение)** и других ARMv7 Kindle.

## Установка

1. Скачайте плагин и распакуйте в `koreader/plugins/qsp.koplugin/`.
2. Убедитесь, что структура такая:

```
koreader/plugins/qsp.koplugin/
├── _meta.lua
├── main.lua
├── qspwidget.lua
├── qspdocument.lua
└── libs/
    └── armv7/
        └── libqsp.so
```

3. Перезапустите KOReader.
4. Откройте QSP-файл через FileManager — тапните на `.qsp`, игра откроется.

## Использование

1. **Открытие игры**: FileManager → папка с `.qsp` → тап на файл.
2. **Навигация**: 
   - Свайп вверх/вниз — прокрутка текста.
   - Тап на `<a href="EXEC:...">` — переход по ссылке в игре.
   - Тап на кнопку действия — выбор действия.
   - Тап на объект (МЕНЮ/ДНЕВНИК/КНИГИ) — открытие объекта.
3. **Размер шрифта**: кнопки `A-` и `A+` в заголовке.
4. **Закрытие**: кнопка `✕` справа в заголовке.

## Структура плагина

| Файл | Назначение |
|------|-----------|
| `_meta.lua` | Метаданные плагина (название, описание) |
| `main.lua` | Регистрация плагина, пункт меню, открытие `.qsp` |
| `qspwidget.lua` | Основной виджет игры: HTML, кнопки, действия |
| `qspdocument.lua` | Фиктивный Document-провайдер для FileManager |
| `libs/armv7/libqsp.so` | Нативная библиотека QSP (не в репо) |

## Зависимости

- **KOReader** v2023.10+ (проверено на v2026.07.1).
- **libqsp.so** — движок QSP (собирается отдельно).
- **MuPDF** — встроен в KOReader, используется для HTML-рендера.

## Известные проблемы

- **Android/ПК не поддерживаются** — libqsp.so собран только под ARMv7.
- **Некоторые игры не открываются** — проверьте кодировку `.qsp` (UTF-32 vs KOI8-R).
- **Медленный рендер длинного текста** — MuPDF рендерит HTML, это ресурсоёмко.
